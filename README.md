# Science 9 — Révision

A responsive, single-file French Grade 9 science study website. Open `index.html` locally or publish to GitHub Pages. No server, dependencies, API keys, or build tools needed.

## Features
- 137 multiple-choice questions across 12 topic areas.
- Early material (pages 1–11) and full unit selection.
- Quiz sessions of 10, 20, 30, or all available questions.
- No question repeats within a session; unseen questions prioritized across sessions.
- Correct-answer feedback in French, with English explanations.
- Session percentages, chapter-level strengths/weaknesses, suggestions.
- Local progress stored in browser localStorage; theme toggle.

## Publish
1. Create a public GitHub repository, e.g. `science9`.
2. Upload `index.html` to the repository root.
3. Open Settings → Pages → Build and deployment, choose Deploy from a branch, branch `main`, folder `/ (root)`, then Save.
4. Wait for GitHub Pages to publish at `https://YOUR-USERNAME.github.io/science9/`.

## Scope
Based on the supplied course-note photographs: pages 1–15, 18, and 20. Missing pages are not represented. Some questions are straightforward practice applications of the supplied concepts, not verbatim copied questions. The simplified B/b dominant/recessive example is a classroom model, not a full description of real human eye-color inheritance.

Progress is saved only in each browser/device. No shared student accounts, server-side scores, or cross-device synchronization.
